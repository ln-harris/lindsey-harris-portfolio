## Immediate Next Steps (5 minutes)

### 1. Update Your Information

Open `index.html` and search/replace:

**Contact Info:**

- Line 337: `your.email@example.com` → Your real email
- Line 341: `https://linkedin.com` → Your LinkedIn URL
- Line 345: Update if you want a different GitHub link

**Hero Section (Lines 87-95):**

- Update GitHub link
- Update LinkedIn link
- Update email

### 2. Test Locally

Just double-click `index.html` - it works in any browser!

### 3. Customize Colors (Optional)

Open `styles.css`, go to line 13-15:

```css
--accent-primary: #6366f1; /* Change to your brand color */
--accent-secondary: #8b5cf6;
```

Try these color combos:

- **Purple** (current): `#6366f1` / `#8b5cf6`
- **Blue**: `#3b82f6` / `#06b6d4`
- **Green**: `#10b981` / `#059669`
- **Pink**: `#ec4899` / `#f43f5e`
- **Orange**: `#f97316` / `#ea580c`

### 4. Add Project Screenshots

1. Take screenshots of your live projects
2. Save them in the `/images` folder
3. Update image paths in `index.html` (lines 224, 258, 292)

### 5. Deploy in 2 Minutes

**Option A - Netlify Drop (Easiest):**

1. Go to https://app.netlify.com/drop
2. Drag your entire portfolio folder
3. Done! You get a live URL

**Option B - GitHub Pages:**

1. Create a new GitHub repository
2. Upload all files
3. Go to Settings → Pages → Enable
4. Your site is live at `username.github.io/repo-name`
